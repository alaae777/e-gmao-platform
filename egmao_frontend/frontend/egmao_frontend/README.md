# e-GMAO — Frontend

Interface web de la plateforme e-learning e-GMAO, développée avec React et Ant Design.

La plateforme permet aux employés de consulter les formations, suivre leur progression, passer des évaluations et consulter leurs certificats.

Elle comprend également un espace d'administration destiné à la gestion des utilisateurs, formations, modules et évaluations.

## 1. Technologies utilisées

- React
- JavaScript
- Vite
- Ant Design
- React Router
- Axios
